# Archive

These files are **not used by the live website** and are kept only for reference. Nothing here was deleted, only moved here on 2026-10-22. Cloudflare still serves this folder publicly, and `robots.txt` asks search engines to skip it.

| Item | Why it was archived |
| --- | --- |
| `deploy_old_copy/` | The old `deploy/` folder, a second copy of the whole site that had drifted out of date. Every newer change in it was merged into the root files first: the cookie quick-answer moved into `functions/api/chat.js`, and the price-sheet version of `orders.html` went into `backend/orders.html`. Includes `index-v2.html`, an early "Frozen Roti Co." prototype. |
| `assets/roti_canai.jpg` | Replaced by `assets/roti_plain.jpg`, the image the storefront actually shows. |
| `assets/roti_leaf.png` | 916 KB PNG replaced by `assets/roti_leaf.jpg` (75 KB) for the splash screen. |
| `assets/cookies.png` | 554 KB PNG. The site uses `cookies.jpg`. |
| `assets/doorgift_full.jpg` | Not referenced. The site uses `doorgift.jpg`. |
| `assets/logo.png` | Identical to `assets/logo-round.png`, which is the one referenced. |
| `assets/logo-card.jpg`, `assets/og-banner.jpg` | Not referenced by any page. The social preview uses `og-image.jpg`. |
| `assets/qr_code.svg` | QR code for printed posters, not used on the site. |
| `assets/favicon.ico`, `assets/favicon-32.png`, `favicon.png` | Duplicate or unused favicons. The site uses the root `favicon.ico`, `assets/favicon-48.png` and `assets/favicon-192.png`. |
| `assets/Poster/colorPallete_Poster.png` | Poster colour swatch, not a website asset. |

To restore something, move it back to its old path. If you move the old `deploy/` copy back, remember it is out of date.
